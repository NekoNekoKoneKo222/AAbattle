# CHAOS SHOGI — マスタリー・覚醒・コイン改善（2026-11）

## 変更点
- オンライン対戦（カジュアル、ランク、2vs2）でカードを実際に使用すると、対局終了時にカードごとのマスタリーXPを獲得します。
- カード使用1回 = 40XP、1対局で同じカードは最大120XP。10レベル制です。
- レベルアップ時は1レベルあたり60コイン獲得。対局精算は対局IDで二重計上を防ぎます。
- マスタリーLv.5以降、所持カードに対して欠片120個で覚醒を恒久解放できます。
- 覚醒はランク戦で無効。その他のオンライン対戦では対象カードを**各対局中初めて使用した際に1度だけ**能力が発動します。
- 通常覚醒は2CP返還、ドビーは+1枚ドロー、アバダ・ケダブラは3CP返還、隕石落下は2CP返還+ドローなどカード別の特殊効果があります（`src/chaos-progression.js`）。
- 同名カードの所持は制作によって最大2枚。制作に必要な欠片はコモン30 / レア90 / SR300 / UR900 / 神話1800です。
- 重複カード変換：C5 / R15 / SR50 / UR150 / 神話300欠片。
- ログイン報酬：100→250コイン。オンライン勝利：60→120コイン、敗北：30→60コイン。毎日の最初の報酬付き対戦ボーナス：50→100コイン。
- 元のガチャ料金は250コイン/パックのままです。初期所持コイン5,500も変更しません。

## 変更対象
- `src/chaos-progression.js`：熟練度計算、覚醒能力。
- `src/chaos-collection.js`：欠片制作、覚醒解放、オンライン結果精算、Neonへの保存。
- `src/chaos-cards.js`：覚醒の初回発動、巻き戻しに対応した使用済みフラグ。
- `src/chaos-online.js`：対戦開始時に所有覚醒カードを読み込む。ランク戦ではボーナス無効。
- `src/chaos-routes.js`：覚醒説明をカード図鑑のAPIへ公開。
- `public/CSH/collection.js`、`collection.css`：マスタリー、覚醒、カード制作UI。
- `migrations/014_chaos_progression.sql`：`chaos_profiles` にJSONB列を追加。
- `test/chaos-progression.test.js` と `test/chaos-collection.test.js`：各種回帰テスト。

## 配備手順
本番Renderへ更新する前に、Neonの`aabattle`本番DBに`migrations/014_chaos_progression.sql`を適用してください。未適用だとプロフィールのUPDATEでカラム不在エラーになる可能性があります。
検証用NeonブランチではALTER TABLEが成功しています。本番の移行はまだ実施していません。
