# CHAOS SHOGI card art

Place an image here with the card ID as its filename, such as `dobby.webp` or `infinity.png`. Supported formats are WebP, PNG, and SVG, in that priority order. The `/api/CSH/cards/:id/art.svg` route serves the added image automatically; if no file exists, it serves the original generated placeholder. No card logic changes are needed.

Use artwork that you created or have permission to publish. A portrait image around 320 × 420 pixels fits the card frame.
